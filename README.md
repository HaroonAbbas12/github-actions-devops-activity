## GitHub Actions DevOps Activity

### Workflows Implemented

- Created and tested a basic GitHub Actions workflow.
- Configured workflows for push and pull request events.
- Set up scheduled workflows using cron expressions.
- Implemented manual workflow execution using `workflow_dispatch`.
- Configured external event triggers using `repository_dispatch`.
- Explored workflow contexts and conditional execution.
- Configured repository variables and encrypted secrets.
- Tested workflows on multiple operating systems.
- Set up and tested a self-hosted runner.
- Implemented matrix builds for different environments.
- Explored dependency caching to improve workflow performance.
- Configured a PostgreSQL service container for database testing.
- Created and tested a JavaScript custom GitHub Action.
